Remaining Lean2rr regression

Life increased from 1.625 s to 1.954 s (+20.21%), while remaining faster than the retained 4.387 s native Lean baseline. This increase was present with PR #980 before the inline-variant fix; the fix restores the stack-growth cases but does not remove this slowdown. Separate back-to-back diagnostic measurements are retained with the report.

TBI regression found and fixed

The initial PR #980 measurements exposed a compiler bug: conditional TBI decoding was also applied to inline [value] enums. Taking their stack addresses kept spill slots alive and prevented LLVM tail-recursion elimination. On the same compiler parent/runtime comparison, functional-queue rose from 36.85 ms / 5.84 MiB to 114.51 ms / 217.91 MiB, and fingertree from 30.77 ms / 6.11 MiB to 94.14 ms / 182.77 MiB. A runtime swap left the regression unchanged; switching nullary encoding to arch-independent restored baseline memory use.

PR #981 restricts TBI tag decoding to boxed layouts and adds an inline-variant lowering regression test. It is merged and backported to the paper compiler. The tables above use fresh measurements after that fix. Diagnostic measurements use three samples and two warmups; final main measurements use ten samples and five warmups. The regressed run was not published as the refreshed dataset.

Method and evidence

Measurements ran sequentially on NVIDIA GB10 Spark, pinned to CPU 19 (performance governor), with compilation finished before timing. The maintained benchmark harness requests five warmups and ten samples within a 300-second case budget; GNU time supplies peak RSS. The tabulated changes are ratios of measured means, not statistical significance claims. Raw timing samples, executable hashes, compiler/source provenance, commands, correctness outputs and the exact backport patch are retained alongside the benchmark data.

The main comparison updates the compiler, bundled libraries and runtime together. Lean2rr isolates the backported patch on its existing paper stack, but comparisons with previous timing samples can also reflect run-to-run machine variation. Native Lean has not been retimed.
